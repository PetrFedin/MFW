# MFW / BFS responsive QA gate — 2026-10-01

This gate makes responsive usability part of the release definition rather than a visual afterthought.

## Automated device-agent matrix

- 360×800 compact phone
- 375×667 compact iPhone
- 393×852 standard iPhone
- 430×932 large iPhone
- 744×1133 compact tablet
- 1024×1366 large tablet
- 1440×900 desktop control

The suite verifies shared MFW/BFS shell reachability, MFW bottom navigation, BFS programme navigation, platform overlays, Admin Console navigation, viewport containment, horizontal overflow and primary touch-target height.

A green automated matrix complements, but does not replace, final real-device Safari/Chrome smoke testing before a public event.
