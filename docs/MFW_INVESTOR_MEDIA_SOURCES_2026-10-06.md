# Investor demo media provenance — 2026-10-06

## Scope

This file documents the remote photography and video references used by the **Moscow Fashion Platform investor-demo visual layer** for the three parallel ecosystem experiences:

1. Moscow Fashion Week (MFW)
2. BRICS+ Fashion Summit (BFS)
3. «Сделано в Москве»

The implementation is deliberately **stateless/read-only** and does not change event, access, Verified, commercial, or analytics authority.

## Visual rule

- one canonical storytelling slot = one image URL;
- the manifest must not contain duplicate image URLs;
- MFW, BFS and «Сделано в Москве» keep their own visual identities;
- the shared investor shell connects them through one account, discovery, agenda, relationship graph, meetings, wallet/continuity and evidence concepts;
- source links remain visible in the product or provenance file;
- public availability is **not** treated as a commercial licence. Rights/licensing must be confirmed before public advertising, paid media or broad commercial reuse.
